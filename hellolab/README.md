# 薛付忠 教授简介

> 山东大学生物统计学教授 · 博士研究生导师

## 现任职务

- 山东大学特聘教授、博士研究生导师
- 山东大学公共卫生学院副院长
- 山东大学健康医疗大数据研究院院长
- 山东省健康医疗大数据科技创新平台管理与研究中心主任

## 学术兼职

- 中华预防医学会健康保险专业委员会主任委员
- 中国卫生信息与健康医疗大数据学会医学统计教育专业委员会副主任委员、理论与方法学专业委员会常务委员
- 中华预防医学会生物统计学专业委员会常务委员
- 国际生物统计学会中国分会（IBS-China）常务理事兼秘书长
- 《中华预防医学杂志》编委、《中国卫生统计》编委

## 研究方向

1. 健康医疗大数据分析方法与转化研究
2. 健康/疾病风险评估与生命历程流行病学理论方法研究与应用
3. 组学大数据统计分析与系统流行病学理论方法研究与应用
4. 观察性研究（大数据）的因果推断方法

## 教育背景

- 2002.09–2005.06 山东大学 流行病与卫生统计学 医学博士
- 1996.09–1999.07 山东医科大学 卫生统计学 医学硕士
- 2005.06–2007.11 复旦大学生物学博士后流动站（统计遗传学与群体遗传学方向）
- 2009.09–2010.10 英国剑桥大学 MRC 流行病学研究所 访问学者
- 2011.10–2012.04 美国加州大学（戴维斯）公共卫生学院 访问学者

## 主要学术成就

- 先后主持或承担国家自然科学基金面上项目 9 项，以及科技部"863"项目、"973"项目分题子课题、国家科技支撑计划项目、国际合作项目、山东省重点研发计划等多项课题
- 以第一作者或通信作者在国内外发表论文 200 余篇，其中 130 余篇被 SCI 收录
- 获省部级科技奖励 3 项（含山东省科技进步一等奖、山东省自然科学创新奖（人才类）一等奖）
- 获国家发明专利 8 项、软件著作权 4 项
- 参编卫生部、教育部规划教材 3 部

## 学科贡献

薛付忠教授带领学科团队在国内率先推行卫生统计学向生物统计学的学科升级换代，大力引进数学/统计学和计算机专业背景的教师与研究生，推动了数据密集型医学（医学 4.0）背景下的"数字智能医学"新医科建设。
